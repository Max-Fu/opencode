Eine Sammlung von Community-Projekten, die auf AlphaCode basieren.

:::note
Möchten Sie Ihr AlphaCode-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-alphacode](https://github.com/awesome-alphacode/awesome-alphacode) und [alphacode.cafe](https://alphacode.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
